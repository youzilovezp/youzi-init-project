# {{ project_title }} 前端

基于 Vue 3 + TypeScript + Vite + Element Plus 的管理系统前端。

## 启动

```bash
pnpm install      # 或 npm install

# 启动开发服务器（默认 http://localhost:3000）
pnpm dev

# 构建生产版本
pnpm build
```

或用工程根目录的 Makefile：

```bash
cd .. && make frontend-dev
```

启动后访问：

- 前端：http://localhost:3000

## 默认账号

`admin` / 启动后端时打印的随机密码（详见后端说明）。

## 项目结构

```
frontend/
├── src/                # 应用代码
│   ├── api/            # 接口层（axios 封装）
│   ├── layouts/        # 布局组件（BasicLayout）
│   ├── router/         # 路由 + 守卫
│   ├── stores/         # Pinia（user / app）
│   ├── views/          # 页面
│   │   ├── dashboard/   # 首页
│   │   ├── login/      # 登录
│   │   └── system/     # 系统管理（用户、角色）
│   ├── App.vue
│   └── main.ts
├── docs/               # 架构/技术栈/配置/开发 文档
├── public/             # 静态资源（含 favicon.svg）
├── package.json
├── vite.config.ts
└── tsconfig.json
```

## 加新业务模块

在工程根目录：

```bash
python backend/scripts/add_module.py order --title "订单管理"
```

脚本会自动生成前端需要的 2 个文件：

- `src/api/order.ts` —— axios 接口
- `src/views/order/index.vue` —— CRUD 页面

并提示你需要做的 2 步：

1. `src/router/index.ts` 添加路由
2. `src/layouts/BasicLayout.vue` 添加菜单项
