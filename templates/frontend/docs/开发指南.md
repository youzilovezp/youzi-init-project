# Youzi Admin 前端开发指南

## 1. 环境准备

- Node.js >= 18
- pnpm（推荐）或 npm

## 2. 安装依赖

```bash
cd frontend
pnpm install   # 或 npm install
```

## 3. 启动开发服务器

```bash
pnpm dev   # 或 npm run dev
```

默认监听 `http://localhost:3000`。

## 4. 配置后端地址

编辑 `.env.development`：

```env
VITE_PROXY_TARGET=http://localhost:8000
```

重启 Vite 生效。

## 5. 添加新页面

以「文章管理」为例：

### 5.1 创建 API 模块（`src/api/article.ts`）

```ts
import request from "./request";

export interface Article {
  id: number;
  title: string;
  content: string;
  author_id: number;
  created_at: string;
}

export function listArticles() {
  return request.get<Article[], Article[]>("/articles");
}

export function createArticle(payload: Partial<Article>) {
  return request.post<Article, Article>("/articles", payload);
}
```

### 5.2 创建页面（`src/views/article/index.vue`）

参考 `src/views/system/user/index.vue` 实现。

### 5.3 注册路由（`src/router/index.ts`）

```ts
{
  path: 'article',
  name: 'Article',
  component: () => import('@/views/article/index.vue'),
  meta: { title: '文章管理', icon: 'Document' },
}
```

### 5.4 添加菜单（`src/layouts/BasicLayout.vue`）

```ts
const menus = [
  // ...
  { path: "/article", title: "文章管理", icon: "Document" },
];
```

## 7. 代码规范

```bash
pnpm lint         # ESLint 检查
pnpm format       # Prettier 格式化
pnpm type-check   # 类型检查
```

## 8. 构建部署

```bash
pnpm build
```

产物在 `dist/`，可使用 Nginx 或任何静态服务器托管。

## 9. 常见问题

### Q: 跨域错误

A: 开发环境检查 `vite.config.ts` 中的 proxy 配置；生产环境通过 Nginx 反代。

### Q: 修改 .env 后没生效

A: 必须重启 Vite 开发服务器。

### Q: 自动导入不生效

A: 确认 `auto-imports.d.ts` 和 `components.d.ts` 在 `tsconfig.json` 的 include 中。
