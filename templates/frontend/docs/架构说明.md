# {{ project_title }} 前端架构说明

> 非技术用户**不需要**读这个文档。仅供工程师了解整体设计。

## 1. 整体架构

```
用户操作
   │
   ▼
Vue 组件（dispatch）
   │
   ▼
Pinia Store（业务编排）
   │
   ▼
API 模块（types/接口定义）
   │
   ▼
request.ts（Axios 拦截器：token / 错误处理）
   │
   ▼
后端 API（http://localhost:8000）
```

## 2. 模块划分

| 目录           | 职责                                                                         |
| -------------- | ---------------------------------------------------------------------------- |
| `src/api/`     | axios 接口（按业务模块拆分：`auth.ts` / `user.ts` / `role.ts` / `stats.ts`） |
| `src/layouts/` | BasicLayout（侧边栏 + 顶栏 + 主内容）                                        |
| `src/router/`  | Vue Router + 全局守卫（鉴权/角色）                                           |
| `src/stores/`  | Pinia（user / app）                                                          |
| `src/views/`   | 页面（dashboard / login / system）                                           |
| `src/types/`   | 全局类型声明                                                                 |
| `src/utils/`   | 工具函数                                                                     |
| `src/config/`  | 应用配置常量                                                                 |

## 3. 鉴权流程

1. 用户在 `/login` 输入用户名密码
2. 调用 `authApi.login()` 拿到 `access_token`
3. 写入 Pinia + localStorage
4. `router.beforeEach` 守卫检查 token，未登录跳 `/login`
5. 已登录但无 `userInfo` 时调 `getMe()` 拉取用户信息
6. 受保护路由检查 `meta.requiresAdmin`

## 4. 加新业务模块

运行：

```bash
python backend/scripts/add_module.py order --title "订单管理"
```

脚本自动生成 6 个文件，详见 [开发指南](开发指南.md)。
